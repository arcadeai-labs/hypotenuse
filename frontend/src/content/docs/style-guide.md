# Style guide

Every piece Hypotenuse draws with, in light and dark side by side: buttons, badges, glyphs, forms, and the surfaces a
project shows — a conversation list, a transcript, a bot, the memory explorer. Each half paints its own theme whatever
yours is set to, so the two can be compared at a glance. The data is made up.

A conversation's state is always drawn with the same glyph; [Getting started](/docs/getting-started) says
what each one means. Every avatar that stands for a bot carries the **bot** badge.
