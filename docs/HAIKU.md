# Un haïku

> ticket délégué —
> sur un portable, la nuit,
> l'arbre prend racine

*(a delegated ticket — / on a laptop, at night, / the tree takes root)*

The tree is the git worktree a runner makes for each issue; in French, a worktree is an *arbre de travail*. The lines
count 5-7-5 as French verse does: a mute *e* is a syllable before a consonant (*por-ta-ble*) and silent at the end of a
line (*ra-ci-ne*).
